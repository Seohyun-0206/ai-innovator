Hybrid LLM Routing Policy

Model Tier Mapping & Routing Rule Reference

v1.0 · 2026-05-22

Tier 정의

Tier 1
Lightweight
Fast Path
낮은 latency와 낮은 비용을 최우선으로 하는 경량 모델 티어. 단순·반복적 요청에서 실시간 응답을 보장한다.
실시간 응답 · FAQ · 단순 질의 · SLA 우선 요청
Tier 2
Standard
General Path
정확도와 latency를 균형 있게 처리하는 범용 모델 티어. 대부분의 업무 질의를 커버한다.
일반 QA · 업무 질의 · 기본 설명
Tier 3
Advanced
Accurate / Escalation Path
높은 정확도와 복합 추론이 요구되는 고난도 요청을 처리한다. 비용과 응답 지연이 수반될 수 있으나 신뢰성이 최우선이다.
고난도 추론 · 정책/규정 QA · 최종 검증 · Escalation
Tier 4
Long Context
Context Path
긴 문맥을 안정적으로 유지하며 처리하는 모델 티어. RAG 및 긴 문서 분석에 특화되어 있다.
문서 QA · RAG · 회의록 분석 · 긴 문서 요약
Tier 5
Structured
Structured Output Path
JSON·SQL 등 구조화된 형식을 안정적으로 생성하는 모델 티어. Format validation과 함께 운영된다.
SQL / JSON 생성 · API 응답 · 정형 출력
